CA FOUNDATION MOBILE CALENDAR

The install-ready app files are in this folder. A downloaded HTML file cannot normally be installed as a home-screen app by itself. Publish the CONTENTS of this folder to a static web host that serves HTTPS. Keep index.html, manifest.webmanifest, sw.js, and all icon files together at the same site path.

Android (Chrome): after publishing, open the HTTPS page on the phone, tap ⋮, then choose Install app or Add to Home screen.
iPhone (Safari): open the HTTPS page, tap Share, then Add to Home Screen.

Ticks are saved in that browser on that phone. After the first successful visit, the calendar can load offline. Checklist data stays in that phone's browser storage.
